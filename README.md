# Garage 1:64

**Built for the collection. Made for the collectors. 🏁**

[**Abrir o app**](https://andreyvenera.github.io/garagem164/)

</div>

Criei a Garage 1:64 para uso pessoal e também para minha família e meus amigos organizarem suas coleções de Hot Wheels no celular. Cada um tem a própria garagem, com fotos, séries e valores, e pode visitar a garagem dos outros.

O app é uma página feita em HTML, CSS e JavaScript no GitHub Pages, com os dados salvos no Google Planilhas. As fotos do catálogo vêm da [Hot Wheels Wiki](https://hotwheels.fandom.com).

Para instalar, abra o link no celular e escolha *Adicionar à Tela de Início*.
